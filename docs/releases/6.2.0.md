# Preparación de email-helper 6.2.0

Fecha de revisión: 26 de septiembre de 2026. Versión preparada localmente; este documento no acredita su publicación.

## Cambios

- Versión del proyecto: 6.1.4 → 6.2.0.
- Parent: jarios-parent 1.0.13 → 1.0.15.
- Dependencias actualizadas por el parent: SLF4J 2.0.18 → 2.0.20, Lombok 1.18.46 → 1.18.48 y Logback de pruebas 1.6.3 → 1.6.4.
- README reorganizado con integración Maven, API, configuración SMTP, manejo de errores, inventario de herramientas y proceso real de publicación.
- Sin modificaciones de API ni de código Java. Se mantiene `maven.compiler.release=21`.

## Revisión de actualizaciones

Se ejecutaron `versions:display-dependency-updates` y `versions:display-plugin-updates`, y se contrastaron las versiones heredadas con los metadatos `maven-metadata.xml` de [Maven Central](https://repo.maven.apache.org/maven2/). El informe de plugins de Versions no mostró todas las actualizaciones heredadas, por lo que se realizó esta comprobación adicional.

- Las seis dependencias directas quedan en sus versiones estables más recientes para sus coordenadas actuales.
- No se adoptan AssertJ 4.0.0-M1 ni SLF4J 2.1.0-alpha1, por ser versiones preliminares.
- `com.sun.mail:jakarta.mail` permanece en 2.0.2. [Eclipse Angus](https://eclipse-ee4j.github.io/angus-mail/) continúa el desarrollo con otras coordenadas; esa migración requiere evaluar compatibilidad y transporte SMTP por separado.
- Maven 3.9.16 y Maven Wrapper 3.3.4 no requieren cambios.
- Los tags remotos de GitHub Actions confirman las versiones ya configuradas: Checkout 7.0.1, Setup Java 5.7.0, Cache 6.1.0 y Upload Artifact 7.0.1. No requieren cambios.
- El parent 1.0.15 también incorpora Failsafe 3.6.0 y Build Helper 3.6.2; estos plugins no se ejecutan en este proyecto.
- Maven Site permanece en la versión 4.0.0-M16 gestionada por el parent; no se utiliza en el ciclo de esta biblioteca. No se sustituye por la rama estable 3.x como parte de esta actualización.

Fuentes para reproducir la comprobación de herramientas:

- [Compiler](https://repo.maven.apache.org/maven2/org/apache/maven/plugins/maven-compiler-plugin/maven-metadata.xml), [Surefire](https://repo.maven.apache.org/maven2/org/apache/maven/plugins/maven-surefire-plugin/maven-metadata.xml).
- [Spotless](https://repo.maven.apache.org/maven2/com/diffplug/spotless/spotless-maven-plugin/maven-metadata.xml), [SpotBugs](https://repo.maven.apache.org/maven2/com/github/spotbugs/spotbugs-maven-plugin/maven-metadata.xml).
- [Versions](https://repo.maven.apache.org/maven2/org/codehaus/mojo/versions-maven-plugin/maven-metadata.xml), [Checkstyle](https://repo.maven.apache.org/maven2/com/puppycrawl/tools/checkstyle/maven-metadata.xml), [Google Java Format](https://repo.maven.apache.org/maven2/com/google/googlejavaformat/google-java-format/maven-metadata.xml).

## Validación

Ejecutado con JDK 21.0.11 y Maven Wrapper 3.9.16:

```powershell
.\mvnw.cmd -B -ntp clean verify -Pquality
```

Resultado: `BUILD SUCCESS`; 19 pruebas, cero fallos, cero errores y cero pruebas omitidas. Spotless valida los 22 archivos Java, Checkstyle informa cero infracciones y SpotBugs cero errores o avisos. Artefacto generado: `target/email-helper-6.2.0.jar`.

Las pruebas no envían correos reales. No se ha ejecutado el análisis OWASP/NVD en esta revisión ni se ha publicado el paquete. La revisión de versiones no sustituye un análisis de vulnerabilidades.

## Publicación

El workflow `release-package.yml` publica desde un tag cuyo número coincide con el POM. Para esta versión corresponde `v6.2.0`, apuntando al commit con estos cambios. La ejecución manual acepta ese tag existente mediante `release_tag`.

Los consumidores que hereden jarios-parent 1.0.15 deben declarar explícitamente email-helper 6.2.0 hasta que su parent gestione esta versión; el parent 1.0.15 aún selecciona 6.1.4.
