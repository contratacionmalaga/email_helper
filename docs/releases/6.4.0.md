# email-helper 6.4.0

- Admite relés SMTP sin credenciales con `mail.smtp.auth=false`. Cuando la autenticación está activa, el usuario y la contraseña siguen siendo obligatorios.
- Incorpora `GraphEmailService` para enviar correo HTML con Microsoft Graph mediante las credenciales de aplicación de Microsoft Entra.
- Requiere Java 21. Los consumidores pueden declarar la dependencia Maven `local.jarios:email-helper:6.4.0`.
